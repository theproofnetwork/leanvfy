# leanvfy end-to-end fixture: challenge

A minimal challenge Lake package for `.github/workflows/e2e.yml` of
[theproofnetwork/leanvfy](https://github.com/theproofnetwork/leanvfy): the
module `Challenge` states `Challenge.main` about the definition in
`Challenge/Defs.lean`. The branch `fixtures/solution` proves it. This branch is
an orphan of the workflow repository so that the fixture is fetchable over
https by the runner without a second repository.
